# M5：高级 Blocker + 优化（按需）

**工期**：按需，预估 2–3 周
**前置依赖**：M4 完成 + 真实业务数据确认确有需求
**输出**：滑块、远程登录、远程接管浏览器、智能派单

## 决策门槛

进入 M5 之前先回答：

1. captcha_slider 在真实业务里频率有多高？低于 1 次/日 → 现场处理就够，不做 M5
2. login_required 频次？正常运营下 cookie 多久过期？
3. 是否需要"操作员远程操控机器人浏览器"的能力？
4. operator 数量增长到需要按熟悉度路由了吗？

只有明确需要的项才做。
