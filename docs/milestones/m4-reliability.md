# M4：可靠性 + 运营化

**工期**：1.5 周（7–8 工作日）
**前置依赖**：M3 完成
**输出**：看板、指标、告警、运维操作全套上线，可正式投产

## 里程碑目标

1. 运营看板：商品、操作员、冻结状态、DLQ
2. Prometheus 指标 + Grafana 模板
3. 告警通道接入（钉钉 / Slack / 短信，任选）
4. 运维能力：踢下线、DLQ 重派、强制 abort、批量管理
5. 优雅关闭（服务端 + 客户端）
6. traceId 全链路日志可查

## DoD（验收标准）

- [ ] 管理后台能看到：所有机器人在线状态、最近 24h 各类任务统计
- [ ] 商品看板：各状态商品数 + 单店铺最近转化漏斗
- [ ] 操作员看板：每人接单量、平均处理时长、派发超时率、unable 率
- [ ] DLQ 列表 UI：能查看任务完整信息、点击重派、点击丢弃
- [ ] 冻结状态总览：当前 frozen 的 (robot, type) + 时长 + 关联 humanTaskId
- [ ] Prometheus 抓到关键指标、Grafana 面板可看
- [ ] 关键事件触发告警：no operator / 总 SLA 超时 / DLQ 增量、客户端长时间下线
- [ ] 服务端 SIGTERM 后正常排空请求、保存状态再退出
- [ ] 客户端关闭时正常 abort 所有任务、ack 服务端
- [ ] 用 traceId 能在日志里查到 monitor→collect→publish 整条链路
